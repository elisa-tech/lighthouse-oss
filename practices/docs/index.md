# Open Source Practices

Explore practices that support the development and long-term health of open source projects. 
The categories provide a grouping starting point for understanding key areas, 
while each category page introduces its scope and links to related practices.

The `*-000.md` files are category overviews. The other files describe
individual practices and link back to their parent category.

## Categories

| ID | 📂 Category | Description |
| --- | --- | --- |
| COM | [Community Health](COM-000.md) | Participation, support, and community resilience. |
| DEV | [Development Practices](DEV-000.md) | The technical workflow and structure of the codebase. |
| DOC | [Documentation](DOC-000.md) | Information for users, contributors, and maintainers. |
| GOV | [Governance](GOV-000.md) | Project direction, roles, and decision-making. |
| QE | [Quality Engineering](QE-000.md) | Review, testing, integration, and quality evidence. |
| SEC | [Security](SEC-000.md) | Vulnerability reporting, response, and remediation. |
| SC | [Supply Chain](SC-000.md) | Dependencies, provenance, licenses, and software composition. |
| SUS | [Sustainability](SUS-000.md) | The project's ability to remain viable over time. |
