# Public vulnerability handling

## Evidence

Practice "Public vulnerability handling" from *2025 - Towards a more
sustainable and secure software tooling in free/libre open source software
environments (S. Tatschner)*, 3.2.2.2. Determination of Relevant
Vulnerability Databases.

> [Page 73 ] “Ecosystem-specific software repositories, such as PyPI
> (for Python) or pkg.go.dev (for Go), maintain their own databases that
> connect NVD database entries with specific software packages.
> Additionally, the status of issues, such as vulnerable or patched, is
> tracked."
