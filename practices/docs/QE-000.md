# Quality Engineering

Quality Engineering provides evidence that the project does not merely
define good practices, but applies them consistently. It supports defect
prevention, maintainability, regression control, and release confidence.

This area is also central to the maturity model in this workbook, because many
of its practices can be assessed using observable evidence such as:

- pull requests
- review records
- CI logs
- test reports
- coding-standard checks
- commit history
- release artifacts

## Scope

Quality Engineering includes:

- peer review
- automated testing
- unit testing
- regression testing
- CI/CD pipelines
- coding conventions
- clean commit history
- quality gates
- test evidence
- build and release checks
- traceability from changes to verification results
- metrics and reporting
