# Clean commit history

## Evidence

Practice "Clean commit history" from *2020 OSS Development Process
Systematic Review (B. Napoleao, F. Petrillo, S. Hallé)*, 3.0.2 OSS process
activities characteristics - Commit the code / 4 Discussion.

> [Page 8] “Commit the code consists of adding source code changes to
> the project repository… to make it available to the community.”

> [Page 10-11] “Successful OSS projects have governance rules…
> restricted access to the source code repository; permission to commit…
> [core developers] will evaluate and decide if they accept or not the
> contributions.”
