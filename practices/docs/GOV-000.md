# Governance

Governance provides predictability and accountability. It helps external
users, contributors, and assessors understand who can make decisions, how
decisions are recorded, and how project direction is established.

## Scope

Governance includes:

- leadership model
- decision-making process
- maintainer, committer, reviewer, and project roles
- process documentation
- roadmap governance
- requirements and feature-decision process
- contribution rules
- escalation and conflict-resolution mechanisms
- policy change process
