# Modular design & clean interfaces

## Evidence

Practice "Modular design & clean interfaces" from *2017 - Evaluation of
open-source OS for Safety-Critical Applications (P. Berntsson)*, 4.1
Safety Requirements for Operating Systems.

> [Page 33-34] “For specifying the detailed software design, it is again
> highly recommended to use... a modular approach with design... If we
> look into the architecture of ChibiOS we can see that it has a modular
> design... internally divided in several major independent components
> where the components themselves are divided in multiple subsystems...
> There are also requirements that the implementation shall be
> verifiable and testable and this is done by the test suite provided."
