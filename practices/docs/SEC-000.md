# Security

Users need to know how a project handles vulnerabilities. This is
especially important for safety-relevant, security-sensitive, or regulated
use cases.

Security practices provide confidence that the project can respond to
vulnerabilities in a predictable and transparent way.

## Scope

Security includes:

- vulnerability reporting process
- vulnerability triage
- security response team or responsible roles
- security advisories
- responsible/coordinated disclosure
- security issue tracking
- security patch process
- public vulnerability status where appropriate
- connection to defect tracking and risk management
