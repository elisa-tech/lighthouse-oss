# Use approved open source software license

Use a license included in the [OSI-approved license list](https://opensource.org/license).
These licenses have been assessed against the
[Open Source Definition](https://opensource.org/osd). 
Both permissive and copyleft OSI-approved licenses satisfy this practice.

## Evidence

In [Tatschner's thesis](https://researchrepository.ul.ie/entities/publication/e4b7b543-f927-4bad-8946-bca9454e48d0),
section 3.3, the "Approved Software License" bullet on page 90 identifies an OSI-approved
license as supporting a project's freedom and independence. Its continuation
on page 91 describes how a community can continue a project after a change to
non-free licensing, using Valkey as an example (paraphrased).
