# Developer documentation

## Evidence

Practice "Developer documentation" from *2020 OSS Development Process
Systematic Review (B. Napoleao, F. Petrillo, S. Hallé)*, 4 Discussion.

> [Page 10] "The existing documentation in OSS can be divided in two
> categories: (i) user documentation that are user instructions
> documented in wiki, project webpages, newsgroups and release roadmap
> lists; and (ii) developer documentation that are messages from mailing
> lists, bugs reports, code guidelines, etc."
