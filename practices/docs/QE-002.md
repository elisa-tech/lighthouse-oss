# Structured peer review with automated testing

## Evidence

Practice "Structured peer review with automated testing" from *2020 OSS
Development Process Systematic Review (B. Napoleao, F. Petrillo, S.
Hallé)*, 3.0.1 OSS Process Activities / 5 Recommendations.

> [Page 6] “Code review can be performed in order to apply code best
> practices, improve the code’s quality…”

> [Page 11] “Another core point in the OSS environment is peer review
> activities. Testing, parallel debugging and code review are activities
> that need to be systematically integrated into an OSS process... CI
> best practices like Test-Driven Development (TDD) (an activity that
> needs to be further explored in the OSS context) and pull requests
> with code reviews can increase the code assertion, reduce technical
> debt and consequently increase delivery quality.”
